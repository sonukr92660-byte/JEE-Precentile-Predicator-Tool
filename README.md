# JEE MASTER TOOL

Welcome to my project! I built this logic-driven web application using Python and Streamlit to simplify the complex and multi-tiered eligibility criteria of the Joint Entrance Examination (JEE) in India. 

As a high school student, I saw many peers struggling to understand whether they qualified for the IIT Rank List due to complicated subject cutoffs and category rules. This tool solves that real-world problem.

## What This Tool Does:
- **Percentile Predictor:** Takes expected marks out of 300 and predicts the student's percentile range.
- **JEE Main Rank Estimator:** Automatically calculates expected All India Rank (CRL) and Category Ranks based on total candidate trends.
- **12th Board Checker:** Validates if the student satisfies the 75% rule (or 65% for SC/ST/PwBD) or top 20 percentile criteria.
- **JEE Advanced Screener:** Checks subject-wise cutoffs for Physics, Chemistry, and Maths alongside total aggregate requirements to see if the student qualified for the IIT Rank List.

## How to Run locally:
1. Install Streamlit: `pip install streamlit`
2. Run the application: `streamlit run app.py`
